# Mic Noize 0.3.0

Обновление интерфейса и механизма обновления после 0.2.14:

- Устранён фриз при пиксельном переходе между разделами: мозаика теперь рисуется одним слоем.
- Добавлено собственное окно обновления с ходом установки и переходом старого и нового окна. В Настройки → Диагностика есть кнопка «Проверить анимацию обновления», которая проигрывает цикл без установки.
- События телеметрии теперь содержат метку поддержки `WindowsUser@ComputerName`, видимую разработчику в панели оператора.

**Переход с 0.2.14:** используйте обновление в программе. Этот переход ещё покажет старый диалог Velopack: новое окно запускает уже установленная версия 0.3.0 при следующем обновлении. Пакет текущей версии сохраняется для отката.

**Переход с 0.2.8:** если старый обновлятор сообщает об отсутствии предыдущего полного пакета, используйте `Repair-0.2.8-update.ps1` из файлов релиза и повторите обновление.

**Проверено:** автоматические проверки, release-сборка и упаковка; предварительный просмотр нового окна. **Не проверено:** полный цикл обновления установленной программы с новым окном, DPI выше 100 %, несколько мониторов, живая отправка метки телеметрии и отключение питания во время обновления.
