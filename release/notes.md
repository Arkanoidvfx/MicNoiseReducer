# Mic Noize 0.2.7

- Исправлен переход с 0.2.5: после установки полный пакет новой версии сохраняется для безопасного отката при следующих обновлениях. В 0.2.6 переход работал, но этот пакет не оставался в папке обновлений.

- Виртуальный микрофон называется **Mic Noize (Thin Audio Gateway)**. Хост сохраняет его привязку, возвращает системную громкость на 100% и снимает системный Mute. Кнопка Mute внутри Mic Noize остаётся главной; физический микрофон не регулируется.
- После выхода из программы устройство остаётся подключённым и передаёт тишину. Фоновый хост восстанавливается после сбоев с ограниченным числом повторов; настройки показывают состояние устройства и действия для восстановления.
- «Обновить устройства» повторно проверяет хост. Изменение линий или переустановка драйвера выполняются через явное восстановление устройства.
- Для одинаковой громкости используется общий режим Windows; монопольный доступ к виртуальному микрофону отключён. Несколько программ могут слушать его одновременно.
- Интерфейс и хост обновляются одним комплектом с сохранением предыдущего пакета и журналом восстановления. Исправлен выход из трея.

**Переход с 0.2.5:** распакуйте `MicNoize-Upgrade-0.2.7.zip`, полностью выйдите из Mic Noize через трей и запустите `MicNoizeUpgrade.exe`. При переносе линии может потребоваться заново выбрать микрофон в Discord. `Setup.exe` предназначен для новой установки; не используйте его поверх 0.2.5.

**Если 0.2.6 уже установлена через Upgrade ZIP:** до следующего обычного обновления поместите полный пакет `MicNoize-0.2.6-win-x64-stable-v2-full.nupkg` из [релиза 0.2.6](https://github.com/Arkanoidvfx/MicNoize/releases/tag/v0.2.6) в `%LOCALAPPDATA%\MicNoize\packages`. Удалять приложение не требуется. Чистая установка 0.2.6 могла уже сохранить пакет; если он там есть, ничего копировать не нужно.

**Проверено:** после перезагрузки устройство сохранило имя, линию и endpoint, громкость 100% и работу хоста в фоне. Прошли проверки синтетического сигнала, двух одновременных программ, микрофона с наушниками, аварийного восстановления, перехода и отката настоящего пакета 0.2.5. Исправление сохранения пакета проверено отдельно.

**Ещё не проверено на этом патче:** сон, физическое переподключение микрофона, повторное открытие потока Discord и чистая установка Windows. Прерывание обновления проверялось имитацией состояния файлов; реальное отключение питания не выполнялось. Гибернация на проверяемом ПК отключена.
