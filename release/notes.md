# Mic Noize 0.2.0

- Внутренние имена приложения, процесса и TAG-устройств приведены к Mic Noize.
- Настройки, runtime и пользовательские модели перенесены в `%APPDATA%\Mic Noize` и переживают удаление программы.
- Основной NVIDIA/TAG runtime обновлён до `runtime-core-v2`; RVC runtime и `mnr_*`-протоколы совместимы без изменений.
