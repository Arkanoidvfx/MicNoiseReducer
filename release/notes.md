# Mic Noize 0.2.5

- Шумодав DeepFilterNet на процессоре (GTX 10xx/16xx, AMD, Intel) больше не рвёт голос. Раньше он обнулял целые кадры, когда считал их шумом, и на шумном USB-микрофоне речь прерывалась и «спотыкалась». Теперь каждый кадр проходит через всю модель, а шум убирается плавно.
- GTX 10xx: если входом выбран микрофон «NVIDIA RTX Voice» (старый RTX Voice работает на GTX) или «NVIDIA Broadcast», Mic Noize свой шумодав не включает: без двойной обработки и без лишних 30 мс. Под ползунками написано «Шум уже убран на входе».
- После установки виртуального микрофона на новом ПК красная ошибка «TAG microphone endpoint not found» больше не остаётся на экране, когда автоперезапуск уже всё запустил.
- Наушники: убрана кнопка «Без звука», галку NVIDIA можно переключать на ходу, новая галка «Реверс». Исправлен отказ «Headphone host rejected request» (стандартные линии TAG занимали место).
- Mic Noize по умолчанию запускается вместе с Windows (в трей); галка в настройках.
- Мелкие правки интерфейса: заметнее шумоподавление, метки 100 % на ползунках, Ctrl+клик сбрасывает ползунок, вкладка Voice Changer в общем стиле.

На слух и на ПК с GTX исправление DeepFilterNet ещё не проверено; работа с RTX Voice проверена только кодом (на ПК разработчика RTX Voice нет).
