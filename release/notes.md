# Mic Noize 0.2.12

Исправлены два дефекта ползунков после 0.2.11:

- Тонкая оранжевая рамка больше не остаётся после работы мышью. При управлении клавиатурой рамка показывается, стрелки по-прежнему меняют значение.
- Перетаскивание «Силы» не обрывается при переходе через 100 %: предупреждающие ленты появляются в красной зоне без перестройки ползунка.

**Переход с 0.2.11:** используйте обновление в программе; пакет текущей версии сохраняется для отката.

**Переход с 0.2.8:** если старый обновлятор сообщает об отсутствии предыдущего полного пакета, используйте `Repair-0.2.8-update.ps1` из файлов релиза и повторите обновление.

**Проверено:** автоматические проверки, release-сборка и упаковка. **Не проверено:** живое перетаскивание через 100 % и отсутствие рамки после мыши в установленной сборке; отключение питания во время обновления.
