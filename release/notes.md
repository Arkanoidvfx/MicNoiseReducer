# Mic Noize 0.2.14

Исправления интерфейса и запуска после 0.2.13:

- Индикатор «До / После» стал спокойнее: шкала начинается с −72 дБ, помехи вне уровня убраны, мерцание «До» мягче и реже.
- Новый логотип реагирует на голос. Пункты меню выровнены; переход между разделами сопровождается короткой пикселизацией. Настройки размещены в двух колонках и обычно помещаются без прокрутки.
- На новой установке оба параметра автозапуска включены по умолчанию: приложение и фоновый виртуальный микрофон. Существующая установка сохраняет прежний выбор для фонового хоста.
- Повторное сворачивание через панель задач снова скрывает окно в трей после его восстановления.

**Переход с 0.2.13:** используйте обновление в программе; пакет текущей версии сохраняется для отката.

**Переход с 0.2.8:** если старый обновлятор сообщает об отсутствии предыдущего полного пакета, используйте `Repair-0.2.8-update.ps1` из файлов релиза и повторите обновление.

**Проверено:** автоматические проверки, release-сборка и упаковка. **Не проверено:** вход в Windows на чистой установке, живые переходы на масштабах 125–200 % и слабом CPU, реальный шум микрофона, отключение питания во время обновления.
