# Mic Noize 0.3.7

Пиксельный переход между разделами стал втрое быстрее: 30 мс вместо 85 мс. Старая страница рассыпается в крупные блоки, новая сразу проявляется из них поверх настоящей.

Исправлено зависание второго обновления подряд без перезапуска программы: окно могло стать прозрачным и не восстановиться. Исправление работает со следующего обновления после 0.3.7; если переход на 0.3.7 из 0.3.6, запущенной обновлением, зависнет — перезапустите программу.

**Переход с 0.3.6:** используйте обновление в программе. Пакет текущей версии сохраняется для отката.

**Проверено:** автоматические проверки, release-сборка и упаковка. **Не проверено:** живое окно после установки, два обновления подряд без перезапуска, отключение питания во время обновления.
