# Mic Noize 0.3.8

Пиксельный переход между разделами больше не тормозит переключение. Новая страница видна сразу, в первом же кадре после клика, как с выключенным эффектом, а её пиксельная мозаика за пару кадров растворяется поверх. Раньше первый кадр показывал старую страницу, и новая становилась чёткой только на четвёртом.

**Переход с 0.3.7:** используйте обновление в программе. Пакет текущей версии сохраняется для отката.

**Проверено:** автоматические проверки, покадровые снимки перехода, release-сборка и упаковка. **Не проверено:** живое окно после установки, ощущение перехода на мониторах с разной частотой, отключение питания во время обновления.
