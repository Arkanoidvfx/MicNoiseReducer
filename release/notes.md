# Mic Noize 0.2.2

- Исправлены пустые разделы саундпада после перехода из длинного списка или изменения поиска.
- При работе через TAG программа удерживает уровень виртуального микрофона Windows на 100 % и компенсирует усиление перед отправкой звука. Это убирает постоянное усиление при обычном общем режиме захвата и не зависит от модели физического микрофона.
- Каждые 50 мс Mic Noize проверяет уровень и системный Mute виртуального микрофона и возвращает нужное состояние после внешнего изменения.

Ограничение: при эксклюзивном захвате Windows обходит программную громкость виртуального устройства, поэтому звук с компенсацией может быть тише. Реальное прослушивание и проверка на других ПК ещё не проводились.
