# Mic Noize 0.2.1

- Программа сама ставит подписанный TAG-драйвер на новом ПК: один запрос прав администратора при первом запуске. Раньше на чистой системе виртуальный микрофон не появлялся вообще (`TAG driver not found`, HRESULT 0x80070490), и поставить его было нечем.
- Если запрос отклонён, в настройках остаётся кнопка «Установить виртуальный микрофон» — повтор без перезапуска программы.
- Микрофон по умолчанию выбирается на любом ПК: берётся устройство связи по умолчанию Windows, а не только HyperX.
- Готовое обновление видно на всех вкладках: панель «Доступно обновление» с кнопкой «Обновить и перезапустить».
- Новая кнопка «Отправить логи разработчику» в настройках.
- Убраны технические сообщения на английском при первом запуске, пока догружается runtime.
