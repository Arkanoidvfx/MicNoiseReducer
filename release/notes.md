# Mic Noize 0.3.5

Индикатор «После» стал спокойнее: пропала контурная метка пика, которая задерживалась впереди уровня и потом опускалась.

У оранжевых ползунков больше нет бегущей подсветки при наведении мыши. Остальные анимации — волна в простое, вспышка края, бегущие цифры — остались. Наведение на ползунок больше не заставляет окно перерисовываться 30 раз в секунду.

**Переход с 0.3.4:** используйте обновление в программе. Пакет текущей версии сохраняется для отката. **Переход с 0.2.8:** если старый обновлятор сообщает об отсутствии предыдущего полного пакета, используйте `Repair-0.2.8-update.ps1` из файлов релиза и повторите обновление.

**Проверено:** автоматические проверки, снимки интерфейса, release-сборка и упаковка. **Не проверено:** живое окно после установки, полный цикл обновления на медленной сети, несколько мониторов и отключение питания во время обновления.
